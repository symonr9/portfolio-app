# Portfolio App Skills

Invoke a skill explicitly with `$skill-name`. Combine one work skill with `$portfolio-finish-change` when implementation should be fully verified or committed.

- `$portfolio-contentful-model-change`: synchronize and publish Contentful schema changes end to end.
- `$portfolio-audit-ux`: browser-test complete user workflows in report-only or fix mode.
- `$portfolio-polish-responsive-accessibility`: improve responsive behavior and accessibility.
- `$portfolio-implement-ui-feature`: build integrated, CMS-driven portfolio UI.
- `$portfolio-debug-contentful`: diagnose GraphQL, publication, preview, cache, and configuration failures.
- `$portfolio-finish-change`: review, verify, stage, and optionally commit completed work.
- `$portfolio-netlify-release-audit`: audit deployment, security, SEO, and production readiness.
- `$portfolio-media-presentation`: implement accessible images, video, embeds, files, and decorative media.
- `$portfolio-research-improvement`: produce sourced, prioritized improvement research without implementation by default.

Example: `Use $portfolio-implement-ui-feature to add related work samples, then use $portfolio-finish-change and commit.`
